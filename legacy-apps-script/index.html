ให้เว็บนี้อ่าน/เขียนข้อมูลกลับเข้าชีตจริงได้ ต้อง deploy สคริปต์เป็น Web App ก่อน:
  1. เปิดชีต -> เมนู Extensions > Apps Script
  2. วางโค้ดจากไฟล์ Code.gs ที่แนบให้ (ลบโค้ดเดิมออกก่อน) แล้วกด Save
  3. Deploy > New deployment เลือกประเภท Web app
  4. ตั้งค่า Execute as: Me, Who has access: Anyone
  5. กด Deploy แล้ว Authorize สิทธิ์ที่ขอ
  6. คัดลอก Web app URL (ลงท้าย /exec) มาวางที่ช่อง "เชื่อมต่อ / แก้ไข URL" ด้านบน
